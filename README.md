# Atlas ERP

Atlas ERP is a cloud-native, multi-tenant enterprise resource planning platform built on Laravel 12, Filament 4, Livewire, PostgreSQL, Redis, and Docker.

This repository currently contains the Sprint 0 foundation:

- authentication and email verification
- shared-database tenancy foundation
- role and permission scaffolding
- activity logging and health monitoring
- settings foundation
- Docker and CI scaffolding
- Pest, PHPStan, and Pint integration

See the [docs](docs) directory for installation, development, Docker, architecture, coding standards, and contributing guidance.
